# FF1 field and battle appearance audit

Field descriptions use the installed sprite keys. The same art can
represent several map placements, so the name of the dialogue speaker and
the description of visible art are separate inputs. The local
`ff1-field-costumes.json` and `ff1-battle-costumes.json` index the exact
bundles and reviewed frame names. Wording awaits localization and integration.
