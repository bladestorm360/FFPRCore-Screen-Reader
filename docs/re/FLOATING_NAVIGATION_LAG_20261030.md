## Correction and ownership

The Data worker prepares an immutable ID index in original order, including
zero/negative IDs, duplicates and conditional companions. Baked actor matching
and derived transportation selectors retain exact type/name/cell/group,
ambiguity and consumption rules. Synthetic grids without a prepared index use
the original linear lookup. Event guards reject another actor's ID before
decoding remaining fields. No bake bytes, terrain, story gate, interaction
geometry or craft capability changes.

EntityCursor shares roots/collection headers only within one read-only native
owner frame, opt-in at FFIII world1 capture producers. A resumed frame replaces
pointers before using them. Collection slots, model enable/identity, positions,
selector lists, trigger power, collision and movement remain current reads.
Pointers remain in the native closure. The same source yields all entity,
collider, model, step-trigger and party sources, preserving cross-list identity.
Other games/maps keep their former capture policy. The0.5ms copy budget and
scheduler budget are unchanged. No timer, hook, wait or cross-frame actor-state
cache is added. entity_cursor.inl is this cohesive existing producer isolated
for its actual before/after source check, not a second enumeration pipeline.

The filter worker marks world1 inventory reusable only after a nonempty complete
capture with no live NPC/party. Published views are reused at the exact same
position/vehicle/script revision, with no pending filter and a ready registry.
Movement, boarding/change, map/settings/script revision or a live NPC invalidates
or disables reuse. Native script completion retains its existing invalidation
ownership; script/transition input guards remain. Every browse/Backslash request
still captures current blockers/craft and proves its route. This avoids a
competing refresh rather than reusing an old selected route.

Literal Current map/World map inventories do not need distances for unique
exits: they sort by physical position and do not prune by distance. Enabled
repeated exit/event groups keep their calculations. Reachability modes and
explicit browse/directions retain route proof. Empty batches skip an unused
flood. The obsolete fourth-mode-only optimization flag and equivalent duplicate
benchmark were removed after migrating this actual shared consumer.

World1 browse records capture elapsed/slices/aggregate native cost, worker queue,
complete compute and request-to-publication time. SpeechTiming still records
input-to-SDK submission and oldest list-row metadata age; a stationary label can
be older while route blockers are freshly captured. Compare both with aggregate
frame/callback metrics. There is no new narration or text-content dedup.
