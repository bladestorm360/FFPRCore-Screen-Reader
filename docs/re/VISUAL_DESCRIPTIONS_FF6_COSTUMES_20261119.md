# FFVI field and battle appearance audit

These descriptions refer to exact installed sprite keys. The same battle
sprite can serve several actors, including the moogles and guest units.
The local `ff6-field-costumes.json` and `ff6-battle-costumes.json` index
the frame and bundle evidence. Wording awaits localization and integration.
