## Producer and ownership

system/key_help.cpp registers KeyHelpController.Initialize as a lower-priority
preload candidate, native UpdateView publication as an actual recent owner, and
OnDestroy prefix as retirement before pointer destruction. Every game's
SetValues calls this same private UpdateView body; the hook is not bypassed by
native inlining. The shared bounded reader in key_help_owned.cpp checks actual
view visibility and serialized contentList/KeyIconView text, not controller
activity or recursive descendants. The native config controls popup retains its
existing dedicated buffer.

preloads. Capture checks at most32 candidates and8 rows per owner-thread slice
under CaptureBudget; each bar allows64 entries, each icon list16, and each text

applicable capture is exhausted. Native publication/destruction, a newer request,
context retirement or hidden chosen view cancels stale speech. Scene changes can
preserve lifecycle-valid controllers that survive additive loads. No scene search,
